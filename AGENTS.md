# AGENTS — TrayMon

Что программа делает — [README.md](README.md). Полные правила — [CLAUDE.md](CLAUDE.md).
Здесь только то, без чего сломаешь продукт.

## Ключевые файлы

- `src/Program.cs` — `--once`, `TrayApp`: тики, слоты иконок, меню, форматирование чисел
- `src/TrayIcons.cs` — отрисовка и регистрация значков через `Shell_NotifyIcon`
- `src/PerfSensors.cs`, `src/Sensors.cs`, `src/HddSensor.cs`, `src/UpsSensor.cs` — источники данных
- `src/Autostart.cs` — задача планировщика AtLogOn / Highest, создаётся из меню самой программой

## Сборка и проверка

```powershell
dotnet publish src/TrayMon.csproj -c Release -o out
out\TrayMon.exe --once     # все значения + стоимость каждого источника в мс
```

Автотестов нет — всё содержательное упирается в железо и оболочку Windows. Роль smoke-теста
играет `--once`: прогонять до и после правки сенсоров, и под администратором, и без.

## Грабли, специфичные для этого проекта

- **Смысл проекта — цена наблюдения:** 0.52 % ядра против 15.8 % у HWiNFO64. Новый
  источник или более частый опрос — только с замером `cost, ms` из `--once`.
- **GUID иконок в `Program.cs` не менять и не перенумеровывать.** Windows держит позицию
  значка привязанной к паре «путь к exe + GUID»; новый GUID сбрасывает её у всех.
  Добавлять только новым суффиксом в конец массива.
- Два запущенных экземпляра дерутся за одни GUID — второй отбирает значки у первого.
  Выглядит как «программа не запускается».
- Числа на значках огрублены намеренно (целые, обороты в тысячах): каждая изменившаяся
  цифра — перерисовка и вызов в оболочку. Десятые доли живут только в подсказке.
- Сеть — в мегабитах, а не мегабайтах: в мегабайтах фоновая нагрузка это круглый `0`.
- GPU — через NVML; `IsGpuEnabled` у LibreHardwareMonitor выключен осознанно (68 мс против 4 мс).
- CPU — со счётчика Hyper-V, если он есть: `\Processor Information` на хосте видит только
  корневой раздел и врёт впятеро.
- Последний значок скрыть нельзя — на значках живёт меню; у вентиляторов и ИБП severity
  инвертирована: тревожны остановка и низкий заряд.
- `LibreHardwareMonitorLib` — только из NuGet: DLL из FanControl вызывает перегрузку
  `Mutex`, которой в .NET 8 нет.
- Репозиторий зеркалится в публичный GitHub: внутренних имён, адресов и путей в коде и
  документации быть не должно. Публикация — `/github-push` со сверкой `.sanitize-patterns`.
